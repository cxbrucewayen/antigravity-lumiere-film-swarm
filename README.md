## Overview / 项目简介

基于 **Google Antigravity /swarm** 构建的全自动化 AI 微电影制片厂多智能体系统——从一句话灵感出发，协同多编剧、导演、分镜师、美术指导、摄影与剪辑工种完成电影制作全工业流程。
